# Bem vindo ao seu Expo app 👋

Isto é um projeto [Expo](https://expo.dev) criado com [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Comece agora

1. Instale as dependências

   ```bash
   npm install
   ```

2. Inicie o app

   ```bash
   npx expo start
   ```

No output, você encontrará opções para abrir o app em um

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), um ambiente limitado para testar o desenvolvimento de apps com Expo

**Sugestão**: depois de iniciar o app, vá até o Android Studio e inicie o emulador. Em seguida, aperte a tecla "a" no terminal para abrir o app no emulador.

Você pode começar a desenvolver editando os arquivos dentro do diretório **app**. Este projeto usa [file-based routing](https://docs.expo.dev/router/introduction).
